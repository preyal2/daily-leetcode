<h2><a href="https://leetcode.com/problems/gray-code">Gray Code</a></h2> <img src='https://img.shields.io/badge/Difficulty-Medium-orange' alt='Difficulty: Medium' /><hr>An <strong>n-bit gray code sequence</strong> is a sequence of <code>2<sup>n</sup></code> integers where:
<ul>
  <li>Every integer is in the inclusive range <code>[0, 2<sup>n</sup> - 1]</code>,</li>
  <li>The first integer is <code>0</code>,</li>
  <li>An integer appears <strong>no more than once</strong> in the sequence,</li>
  <li>The binary representation of every pair of adjacent integers differs by <strong>exactly one bit</strong>, and</li>
  <li>The binary representation of the <strong>first</strong> and <strong>last</strong> integers differs by <strong>exactly one bit</strong>.</li>
</ul>
<p>Given an integer <code>n</code>, return <em>any valid <strong>n-bit gray code sequence</strong></em>.</p>
