# 🤝 Contributing to Daily LeetCode

Thank you for your interest in contributing to **daily-leetcode**! Contributions from the community are always welcome.

---

## 📌 How You Can Contribute

1. **Add New Solutions**: Submit solutions for problems not yet in the repository.
2. **Optimize Existing Solutions**: Provide more optimal time or space complexity implementations.
3. **Add Multi-Language Support**: Add alternative implementations (e.g., Python, Java, C++, TypeScript, Go).
4. **Improve Documentation**: Enhance problem explanations, time/space complexity analysis, or approach walkthroughs.

---

## 🚀 Contribution Workflow

### 1. Fork the Repository
Click the **Fork** button at the top right of this repository to create your own copy.

### 2. Clone Your Fork
```bash
git clone https://github.com/<your-username>/daily-leetcode.git
cd daily-leetcode
```

### 3. Create a New Branch
```bash
git checkout -b feature/problem-name
```

### 4. Add Your Problem Solution
Follow the repository's directory naming structure:
```text
<problem-number>-<problem-slug>/
├── README.md
└── <problem-slug>.<extension>
```

Example:
```text
121-best-time-to-buy-and-sell-stock/
├── README.md
└── best-time-to-buy-and-sell-stock.py
```

### 5. Code Guidelines
- Write clean, well-formatted, and readable code.
- Include comments explaining key algorithmic decisions.
- Add time and space complexity annotations (`O(N) time, O(1) space`).

### 6. Commit and Push
```bash
git add .
git commit -m "feat: add solution for <Problem Name>"
git push origin feature/problem-name
```

### 7. Open a Pull Request (PR)
- Go to the original repository on GitHub.
- Click **Compare & pull request**.
- Provide a brief description of your solution and approach.

---

## 📜 Code of Conduct
Please be respectful and supportive to fellow contributors. Happy Coding! 💻🚀
