<h2><a href="https://leetcode.com/problems/reorder-list">Reorder List</a></h2> <img src='https://img.shields.io/badge/Difficulty-Medium-orange' alt='Difficulty: Medium' /><hr><p>You are given the head of a singly linked-list <code>L<sub>0</sub> -> L<sub>1</sub> -> ... -> L<sub>n - 1</sub> -> L<sub>n</sub></code>.</p>
<p>Reorder the list to be: <code>L<sub>0</sub> -> L<sub>n</sub> -> L<sub>1</sub> -> L<sub>n - 1</sub> -> L<sub>2</sub> -> L<sub>n - 2</sub> -> ...</code></p>
<p>You may not modify the values in the list's nodes. Only nodes themselves may be changed.</p>
